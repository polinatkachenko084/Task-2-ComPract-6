# Task-2-ComPract-6
Умова задачі
Задано одновимірний масив A(N). Потрібно видалити з нього елемент із заданим номером k та вивести новий масив.
У програмі нумерація елементів для користувача починається з 1: A[1] ... A[N]. Оскільки в C++ індекси масиву починаються з 0, під час обробки використовується індекс k - 1.

Що робить програма
1. Запитує розмір масиву N.
2. Перевіряє, що N є додатним числом.
3. Виділяє динамічну пам’ять для початкового масиву.
4. Зчитує елементи масиву з клавіатури.
5. Запитує номер елемента k, який потрібно видалити.
6. Перевіряє, що k знаходиться в межах від 1 до N.
7. Створює новий масив розміром N - 1 без вибраного елемента.
8. Виводить початковий масив і масив після видалення.
